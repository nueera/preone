# Admin Module Icons

Drop 16 SVGs here, one per module key. Each file should be named `<key>.svg` where `<key>` matches an entry in `src/components/admin/module-icons.tsx`.

## Guidelines

- **Size:** 96×96 SVG viewBox
- **Background:** Transparent
- **Colors:** 1–2 colors, playful preschool aesthetic
- **Style:** Custom illustrated icons (NOT generic UI icons)
- **Format:** Optimized SVG, no unnecessary metadata

Until custom assets are added, the UI renders lucide-react fallback icons automatically.
